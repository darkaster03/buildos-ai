# User Roles

## Site Engineer

Responsibilities

- Capture site progress
- Upload photos
- Record voice updates
- Submit Daily Progress Report

Pain Points

- Too much paperwork
- Time wasted writing reports
- Searching WhatsApp for old updates

Goals

- Finish reporting in under 5 minutes
- No manual typing
- Easy access to previous reports

---

## Project Manager

Responsibilities

- Review daily reports
- Monitor project progress
- Approve reports

Pain Points

- Calling engineers repeatedly
- Inconsistent reports
- No live visibility

Goals

- See project status instantly
- Approve reports quickly

---

## Director

Responsibilities

- Monitor all projects

Pain Points

- No centralized visibility
- Delayed information

Goals

- Know project health instantly
- Identify risks early
